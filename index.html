Возможности Архитектура

О проекте

Полнофункциональная учебная платформа для проектирования и пошагового выполнения алгоритмов на абстрактной машине Тьюринга. Предоставляет преподавателю инструменты для создания заданий и проверки решений, а студентам — удобную среду для написания и отладки программ МТ.

Проект разработан в рамках курсовой работы группы РИС-24-2 как пример применения клиент-серверной архитектуры, ролевой модели доступа и асинхронных уведомлений в реальном времени.

Ключевые возможности

🎯

Визуальный конструктор МТ

Интерактивная лента, таблица состояний и переходов, поддержка произвольного алфавита и редактирования ячеек по двойному клику.

⚡

5 режимов выполнения

Пошаговое выполнение, запуск с регулируемой скоростью (от очень медленной до очень быстрой), мгновенное выполнение с защитой от зацикливания.

👥

Ролевая модель

Три уровня доступа: Администратор, Преподаватель, Студент. У каждого — собственный набор окон и прав.

📚

Управление курсами

Преподаватель создаёт курсы, привязывает группы, формирует задания пяти типов и настраивает индивидуальную формулу оценки.

📝

Полный цикл сдачи работ

Черновики, отправка на проверку, отзыв работы до проверки, оценивание с комментарием преподавателя, отзыв оценки.

🔔

Real-time уведомления

Через SignalR клиент мгновенно узнаёт об изменении профиля, скрытии задания, удалении курса или принудительном завершении сессии.

🔐

Защищённая аутентификация

Хеширование паролей BCrypt, защита от перебора (5 попыток / 15 минут), запрет двойного входа, обязательная смена временного пароля.

📊

Аналитика успеваемости

Автоматический расчёт итоговой оценки по гибкой формуле курса, детализация по каждому студенту, фильтры и поиск.

💾

Импорт / экспорт программ

Сохранение конфигурации МТ в формате .turing и .txt, выгрузка истории выполнения по шагам.

Архитектура

🖥️ Клиент

  • Платформа: Windows Forms, .NET Framework 4.8
  • Язык: C# 8.0
  • UI: кастомные контролы (TapeControl, TapeRenderer)
  • HTTP: HttpClient + Newtonsoft.Json
  • Real-time: Microsoft.AspNetCore.SignalR.Client

⚙️ Сервер

  • Платформа: ASP.NET Core 8 (Minimal API)
  • ORM: Dapper (легковесный микро-ORM)
  • БД: PostgreSQL
  • Auth: сессионные токены + BCrypt.Net-Next
  • Push: SignalR Hub с автоматическим reconnect

🗄️ Слой данных

  • Users, Groups, Courses, CourseGroups
  • Assignments, Submissions
  • Sessions с защитой от двойного входа
  • LoginAttempts (защита от перебора)
  • Оптимистичная блокировка через Version
