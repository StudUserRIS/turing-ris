# Интерпретатор машины Тьюринга — сайт-визитка

Это исходники сайта-визитки проекта **«Интерпретатор машины Тьюринга»**, размещённого по адресу **[turing-ris.is-a.dev](https://turing-ris.is-a.dev)**.

## О проекте

Курсовая работа группы РИС-24-2 — клиент-серверная обучающая система для проектирования и пошагового выполнения алгоритмов на машине Тьюринга. Включает:

- WinForms-клиент (.NET Framework 4.8, C#)
- ASP.NET Core 8 backend с PostgreSQL и SignalR
- Ролевую модель (Администратор / Преподаватель / Студент)
- Полный цикл управления курсами, заданиями и оценками

## Технологии сайта-визитки

- Чистый HTML5 + CSS3, без фреймворков
- Адаптивная вёрстка
- Хостинг: GitHub Pages
- Домен: is-a.dev
